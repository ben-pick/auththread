# NNNN. What is true, as a noun phrase

## Outcome

What is true now, in present tense. One to five short paragraphs or bullets.

## Rules

- The code must / must not ...
- Concrete and checkable, naming the file or command that enforces it.

## Why

At most two sentences. No alternatives list and no story.
