# 0008. Page snippet supply chain is manual in v0.1

## Outcome

- `page/snippet.js` ships as a plain script with no dependencies and no build step.
- The customer serves it, versions it and pins it with Subresource Integrity.
- There is no signed release, npm provenance record or SRI manifest generated by this repo.

## Rules

- The snippet never reads form values, passwords, tokens or one-time codes.
- A change to the snippet is a change to a file customers paste into a login page. Call it
  out in the changelog.
- The page README states the custom domain requirement and the reset-password gap.

## Why

`PLAN.md` wants a versioned, SRI-pinned artifact. A build pipeline for one 60 line script is
not the v0.1 bottleneck, and shipping an unsigned hash would look stronger than it is. The
manual step is recorded so nobody assumes provenance exists.
