# @auththread/oidc

Generic OIDC browser tracing for any standards-based provider.

## Install

```sh
pnpm add @auththread/oidc
```

## Usage

```ts
import { oidcAdapter } from "@auththread/oidc";
import { oidcBrowser } from "@auththread/oidc/browser";
```

## Documentation

See the [auththread repository](https://github.com/ben-pick/auththread) for the
full documentation, deployment instructions and conformance rules.
