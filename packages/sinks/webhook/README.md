# @auththread/sink-webhook

HMAC-signed journey webhook.

## Install

```sh
pnpm add @auththread/sink-webhook
```

## Usage

```ts
import { createWebhookSink } from "@auththread/sink-webhook";
```

full documentation, deployment instructions and conformance rules.
