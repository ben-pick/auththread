# @auththread/schema

Neutral auth journey types, redaction and deterministic identifiers.

## Install

```sh
pnpm add @auththread/schema
```

## Usage

```ts
import { newTraceId, redactSpan, toWideEvent } from "@auththread/schema";
```

## Documentation

See the [auththread repository](https://github.com/ben-pick/auththread) for the
full documentation, deployment instructions and conformance rules.
