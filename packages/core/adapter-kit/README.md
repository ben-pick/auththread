# @auththread/adapter-kit

Provider, runtime and sink contracts with the conformance suites that define support.

## Install

```sh
pnpm add @auththread/adapter-kit
```

## Usage

```ts
import {
  createMemoryBuffer,
  createMemoryScheduler,
  createStaticSettings,
} from "@auththread/adapter-kit";
```

## Documentation

See the [auththread repository](https://github.com/ben-pick/auththread) for the
full documentation, deployment instructions and conformance rules.
